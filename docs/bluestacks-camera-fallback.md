# 블루스택 카메라 없는 환경과 앱 아이콘

2026-11-03 변경 사항.

- 앱 아이콘: 연분홍 바탕, 장밋빛 첫 발자국과 벚꽃. adaptive/round/monochrome 및 API 24~25용 legacy 아이콘 교체.
- 테스트 모드의 사진 미션 상단에 **테스트 이미지로 진행** 추가. 카메라 권한이나 촬영 장치가 없어도 사용 가능.
- 테스트 이미지는 앱이 생성한 캠퍼스 그림이며 이미지 안과 확인 화면에 **실제 촬영 아님**을 표시.
- 확인 → 시설 질문 → 완료 저장 → 다음 미션 해금·시설 도감 조회로 이어짐.
- 테스트 이미지 수행 방식은 `DEMO_PHOTO`. 실제 촬영 `PHOTO`와 분리되며 DEMO 사진 미션에서만 저장 가능. 현장 모드에는 버튼이 없고 저장 정책에서도 차단.
- 미리보기 화면 재생성 후에도 이미지 경로와 수행 방식 복원. 카메라 촬영이 지연되어도 테스트 이미지 버튼으로 빠져나갈 수 있으며 늦은 콜백은 무효화.
- 실제 촬영은 후면 카메라 우선, 없으면 전면 카메라 사용. 연결 실패는 화면에 지속적으로 안내하고 재연결 버튼 제공.

## 검증

- `testDebugUnitTest assembleDebug lintDebug`: 빌드 성공, 단위 테스트 35개 통과.
- Android API 35 에뮬레이터 계측 테스트 5개 통과. 새 테스트는 대체 이미지 미리보기 복원, 실제 이미지 파일 저장, `DEMO_PHOTO` 기록, 현장 모드 기록 분리, 앱 재진입 후 도감 표시 확인.
- 기존 가상 카메라 촬영을 포함한 5미션 연결 테스트도 통과.
- Windows에서 인식되는 카메라 장치 없음, 블루스택 앱 카메라 권한 허용 상태 확인. 블루스택에 업데이트 APK 설치.
- 실제 캠퍼스 촬영·GPS·AR·센서 검증을 대체하지 않음.

# Korean department offline guide

The existing guest and Campus Home routes open `GuideActivity`. Its software introduction offers **국어국문학과 안내 보기**, which opens a second instance with the fixed internal action `com.example.firststep.guide.KOREAN`. The Korean guide has its own model, questions and saved Bundle. Its return action finishes that instance and reveals the original software guide with its practice state intact. Both instances retain their normal Back and guide/quiz navigation.

The Kotlin-free Java/XML screen reuses the teammate guide cards, source sections and transient practice. The Korean header remains identifiable on guide, practice and results. It contains four sourced sections and three questions about the office, study topics and official information. The office address is explicitly an office, and arrival remains unverified. Source buttons open the exact official URLs only on a user tap. The asset loads locally.

`GuideDecoder.KOREAN_DATASET_ID` is `korean_guide_v1`, with target `humanities_korean`. `GuideDecoder.isRegistered(id)` accepts the software and Korean guide IDs. `AssetGuideRepository(Context, String datasetId)` selects their hardcoded asset paths and validates their separate claim, answer and source allowlists. The existing constructor defaults to software. `GuideAdapters.create(Context, String)` composes the requested loader and source opener. `GuideViewModel` verifies that the loaded and restored dataset match the selected instance.

The Korean guide uses transient `PracticeSession` results. Its Kangrin preview uses the same artwork, card and `NarrationActivity` with a Korean script. The existing local DEMO belongs to the software guide. The selected facts were checked against official pages on 2026-11-21. [Official college listing](https://www.kunsan.ac.kr/index.kunsan?contentsSid=7359&sso=ok), [office](https://www.kunsan.ac.kr/korean/index.kunsan?menuCd=DOM_000001101004000000), [overview](https://www.kunsan.ac.kr/korean/index.kunsan?menuCd=DOM_000001101002000000), [department home](https://www.kunsan.ac.kr/korean/index.kunsan)

`KoreanGuideRouteTest` exercises actual guest and Campus Home consumers with account-free identity/Home dependencies. It checks Korean practice selection, recreation and fresh-model restore, return to the software answers, software-only controls and unchanged database hashes. It accepts `koreanGuideOrientation=1` or `2`. The JVM checks validate separate decoder registrations. Builds and source review are distinct from the pending isolated runtime run. ## Korean Kangrin preview

`NarrationActivity.koreanIntent(Context)` returns an internal explicit intent with a fixed action for this department. It loads `korean_narration_v1` and its matching guide sources. `NarrationAsset.load(Context, String narrationId)` accepts the two registered narration IDs. The original overload defaults to software. `NarrationContent` checks the selected dataset, seven ordered sentences, and dataset-specific provenance and claim identities.

The preview begins with a fictional Kangrin greeting and follows the Korean guide's approved source packet. Previous, Next and Replay remain explicit actions. Existing optional Korean speech uses the current sentence and reports availability separately. Back returns to the Korean guide. Finish and Skip return a result that opens or resumes that instance's Korean practice. The preview restores its sentence across recreation. `KoreanGuideRouteTest` covers the guest-to-card route, Back, Skip, Finish, recreation, retained Korean answer and speech-unavailable behavior. `NarrationParserTest` covers exact bundled Korean copy and dataset/claim rejection.

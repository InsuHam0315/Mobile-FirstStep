# 2026-11-05 개발·시각 검증 기록

## 확인한 범위

- 공식 출처를 연결한 시설 8개 검색·분류·기기 내 즐겨찾기 화면을 추가했다. 계정 간 즐겨찾기 동기화는 구현하지 않았다.
- 개발 빌드에 카메라·AR·지도·센서 확인 진입 화면을 추가했다. 탐방 완료를 자동 처리하는 기능이 아니다.
- API 35 에뮬레이터에서 CameraX 가상 장면 미리보기, JPEG 촬영, 파일 디코딩, 화면 재생성 후 사진 유지가 확인됐다. 실제 캠퍼스 촬영 증거가 아니다.
- 지도에 국립군산대 주변 OpenStreetMap 타일과 주입한 위치를 표시했다. 화면에 가상 좌표임을 표시한다. 실측 좌표나 현장 GPS 정확도 검증이 아니다.
- 단위 테스트 40개, VisualToolsTest의 Android 계측 테스트 2개 통과. assembleDebug 성공. lintDebug 오류 0개·경고 94개. 이번에 기존 Android 테스트 전체 또는 서버 테스트 전체를 다시 실행한 것은 아니다.

## 이미지

- `camera-preview.png`: 실제 APK의 CameraX 화면, 입력은 에뮬레이터 가상 방.
- `camera-captured.png`: 위 입력으로 촬영한 JPEG 확인 화면.
- `campus-location.png`: 실제 지도 타일과 주입한 테스트 위치.
- `facilities.png`: 시설 검색 화면.
- `ar-initial.png`, `ar-api33-start.png`: AR 진단 중 실패/미완료 상태이며 성공 증거로 사용하지 않는다.

## 미해결 및 환경

- PC에서 사용 가능한 웹캠이 열거되지 않았다. iPhone+Camo는 사용자가 연결한 후 Windows 미리보기와 에뮬레이터 웹캠 인식을 각각 검증해야 한다. 연결 가능성을 이 PC의 검증 완료로 설명하면 안 된다.
- API 35에서는 ARCore가 요구하는 카메라 ID와 제공되는 ID가 달라 초기화가 실패했다.
- 별도 API 33 환경에서는 카메라 ID 조건을 충족해 세션을 시작했으나 프레임 타임스탬프 오류와 빈 화면이 관찰됐다. 평면 추적·앵커 배치 성공은 아직 확인하지 못했다.
- 공식 Emulator 36.4.10을 기존 SDK와 별개로 `.local/emulator-ar-stable`에 준비했다. 이 기록 시점에는 해당 버전으로 AR 성공을 검증하지 않았다.
- 실제 출입구·시설 좌표·보행 경로·층별 현황·촬영 허용 구역은 현장 확인 전이다.

## 교수 피드백에 따른 우선순위

시설의 실제 용도와 학습 목표를 정하고, 장소 활동·복습 문제·다음 목적지 선택을 설계한 후 미션을 변경한다. 현재 손으로 조도 센서를 가리기, 휴대전화 움직임 5회는 시설을 이해하는 목적과 연결이 약하다.

현재 코드는 OCR, 직접 자이로 센서 측정, 걸음 수 측정을 구현하지 않는다. 방향은 회전벡터 또는 가속도·지자기 센서를 사용한다. AR는 세션 내 평면 앵커 방식이며 건물 인식이나 영구적인 장소 고정 방식이 아니다.

# 후속 개발 독립 검토

기준 커밋: `3b6b9e3`. 검토일: 2026-11-02. 소유권은 이 문서에 한정하며 앱 코드는 수정하지 않았다. 빌드와 에뮬레이터 조작은 총괄/구현 PM이 담당한다.

## 현재 판정

지도·방향센서·5개 미션·진행 복원의 소스 경로와 아래 주요 수정 사항을 확인했다. 현재 소스에서 알려진 중대 차단 사항은 없다. 실제 기기의 센서와 검증된 좌표에서의 현장 동작을 완료로 판정하지 않는다. 최종 품질 게이트, 5개 미션과 저장 복원 실행 결과까지 실행 검증의 최종 통과는 보류한다.

## 전달한 수정 사항

1. **P1 수정 확인 — 완료 사진 삭제 경쟁.** 재생성된 `SAVING`/`SUCCESS` 체크포인트의 사진을 Room 확인 전에 삭제할 수 있던 문제는 `reconciling` 중 이탈 차단과 확인 전 사진 보호로 수정되었다. DB에 기록이 없으면 임시 소유권으로 되돌아간다. 소스에서 확인했다.
2. **P2 수정 확인 — 저장 중 체크포인트 초기화 후 임시 사진 누적.** `clearMode()`가 `SAVING`을 포함한 선택 모드의 사진 후보를 모은 뒤, 테스트/현장 양쪽 DB 참조를 확인하여 미참조 앱 내부 파일만 정리하도록 수정되었다. 디렉터리 전체 스캔을 추가하지 않았다.
3. **P2 수정 확인 — 나침반 대체 센서의 이전 벡터 재사용.** 정확도 불량 시 센서별 벡터 보유 플래그·정확도·시각을 무효화하고, 두 입력 모두 500ms 이내이며 역행하지 않을 때만 방위를 게시하도록 수정되었다. 미션은 중단 알림에 챌린지를 초기화한다.
4. **P2 수정 확인 — 지도 저장소 종료 경쟁.** 타일/메타데이터 임시 파일을 요청마다 고유하게 생성하고, 종료 상태에서 게시를 막고, 진행 HTTP 연결을 추적·해제하도록 수정되었다. 화면 중지 상태는 새 요청을 막으며 전체 캐시 스캔을 추가하지 않는다.
5. **P2 수정 확인 — 지도 HTTP 캐시 처리.** `HttpFreshness`가 `max-age`/`Age`/`Expires`/`no-cache`/`no-store`를 해석한다. 메모리 항목도 만료하며, 비저장 응답은 현재 보기 동안만 사용하고 영구 파일을 제거한다. 기존 타일의 네트워크 갱신 실패 시 일시적으로 이미 받은 PNG를 보여 주되 60초 재시도 억제를 유지한다. 선택적 추가 보완: `must-revalidate`와 같은 엄격한 지시가 온 경우 실패 시 이전 이미지 사용을 금지하는 상태도 영속화할 수 있다.
6. **P2 수정 확인 — 지도 표시 위치의 만료 계산.** 표시를 `10000 - age`의 잔여 유효시간으로 만료시키도록 수정했다. 미션의 도착 판정과는 별도다.
7. **수정 확인 — 저장 복원 시 사진 경로 불일치.** DB에 이미 저장된 사진과 다른 체크포인트 사진을 교체하는 분기는 양쪽 DB 소유권을 확인하는 `cleanupDraft()`로 정리하도록 수정되었다. 기존 저장 사진 보호와 별도 임시 사진 정리를 함께 유지한다.

## 확인한 구조

- 지도 타일 요청은 실제 `onDraw()`의 현재 뷰포트 키 집합으로 제한되고, 큐의 작업도 다운로드 직전 현재 집합을 확인한다. 타일 다중 줌 선적재, 지역 일괄 다운로드, 전체 캐시 디렉터리 순회는 찾지 못했다. 메모리 캐시는 16MiB이고 네트워크 작업자는 2개다.
- HTTPS 공식 타일 주소, 앱 식별 User-Agent, 지도 옆의 눈에 보이는 출처 링크, ETag/Last-Modified 조건부 요청이 존재한다. 실패별 60초 억제가 있어 단순 오류-다시그리기만으로 즉시 반복 요청하지 않는다.
- 정책 기준은 [OSMF Tile Usage Policy](https://operations.osmfoundation.org/policies/tiles/)를 2026-11-02 확인했다. 현재 뷰포트 요청만 허용하고 사전 수집을 금지하며, 서버 캐시 지시 준수를 요구한다.
- 후보 시설의 좌표는 여전히 미검증으로 유지한다. Mission 생성자가 비정상 좌표를 정규화하여 `coordinateVerified`를 false로 바꾸고 위경도를 제거한다. 지도는 검증된 미션만 마커로 표시한다. 공개 학교 지도 중심값은 미션의 방문 검증 좌표와 분리되어 있다.
- 지도 현재 위치는 별도 표시일 뿐 도착 판정을 부여하지 않는다. 화면 중지 시 구독/만료 타이머를 해제하고 위치 표시를 지운다.
- 체크포인트는 모드와 미션별 키로 구분되며 위치·센서 측정값을 저장하지 않는다. 백그라운드 복귀 시 현장 도착을 다시 확인한다. 행동 도중의 조도/움직임/나침반 유지 상태를 복원 완료로 인정하지 않는다.
- 나침반은 회전벡터 우선, 가속도+자기장 대체, 화면 회전 보정, 현장 진북 편각, 다음 검증 지점의 방위를 구분한다. 테스트 목표 0도는 실제 캠퍼스 경로라는 안내와 분리한다.
- 완료 방식은 미션 유형과 짝을 확인하여 저장하고, LEGACY는 이미 존재하는 기록에만 허용한다. 마지막 기록 화면은 선택한 모드의 저장 결과에서 파생되며 기록을 새로 부여하지 않는다.

## 검증 해석

`ThreeMissionFlowTest`는 이름과 달리 현재 5개 미션을 연결하도록 확장 중이다. 소스상 실제 사진 촬영, 조도 대체 길게 누르기, 음성 대체 직접 입력, 방향/움직임 대체 조작, Activity 재생성, 저장 중 체크포인트 복원을 다룬다. 실행 통과 여부는 최종 산출물을 확인한 후 기록한다. 검토 중 읽은 기존 JUnit 산출물은 2026-11-02 20:46:52 KST 기준 30개/실패 0/오류 0, Lint 오류 0/경고 77이며 최신 HTTP 캐시 변경 이전 결과다. 최신 결과는 `VERIFICATION.md`를 따른다. 나침반·움직임의 순수 테스트 통과와 대체 조작 실행은 실제 기기 센서 검증을 대신하지 않는다.

OSM 서비스는 외부 네트워크이며 실제 지도 타일/권한 거절/연결 끊김의 동작은 별도 실행 검증 대상이다. 현장 좌표, 실제 보행 경로, AR 추적/평면 선택, 자기장 간섭, GPS 도착/이탈은 현장 검증으로 남는다.
